Verifier gates

Inspired by the verifier service in the credential work, which enforces its checks in a fixed order.

  1. Gate 1

    Purpose

    "purpose not allowed"

  2. Gate 2

    Nonce

    "nonce already used"

  3. Gate 3

    Issuer

    "issuer not trusted"

  4. Gate 4

    Revocation

    "credential revoked"

  5. Gate 5

    Disclosure

    "requested field not disclosable"

What it proves

Fail-fast ordered verification, purpose binding, replay protection via a single-use nonce, revocation handling, and minimal disclosure.

What it does not do

No cryptography, no real issuer, no real credential format.
